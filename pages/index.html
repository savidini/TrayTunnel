VPN CLI Tray

A small Windows notification-area app for Cisco Secure Client 5.x and legacy AnyConnect 4.x.

Install · Update · Uninstall

Open the manager in Windows PowerShell

& ([scriptblock]::Create((irm 'https://savidini.de/VpnCliTray/manage.ps1')))

Run this as your normal Windows user, not as Administrator.

Before connecting: disable autostart for Cisco's own VPN UI, or fully exit it from the notification area. Leave Cisco's VPN agent service running.
