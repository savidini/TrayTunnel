For Windows 10 & 11

Your Cisco VPN, one click away.

One-click tray control for your existing Cisco Secure Client or AnyConnect installation.

  • No admin
  • Per-user
  • MIT

Install

One command to install.

Open Windows PowerShell as your normal user, paste, and press Enter.

& ([scriptblock]::Create((irm 'https://savidini.de/TrayTunnel/manage.ps1'))) -Action Install

Requires Windows PowerShell 5.1 and an existing Cisco VPN client.

Adds a Start Menu shortcut, starts with Windows, and launches the tray.

Review source SHA-256

Everyday use

The whole app, at a glance.

Tray icon only, with no dashboard or open window.

  • Left-clickConnect, disconnect, or cancel.
  • Right-clickStatus, settings, startup, and exit.

Dot status

  • Grey · Disconnected
  • Amber · Connecting / disconnecting
  • Green · Connected
  • Red · Error / connection lost

Your password is protected with Windows DPAPI for your user.

Later

Install, update, or uninstall.

Run the same command without -Action Install to open the manager menu.
